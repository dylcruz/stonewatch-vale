# Stonewatch Vale

Stonewatch Vale is a single-player 3D action RPG prototype set in a large, hand-authored leveling zone. Play as a human Warrior of the Dawnward Compact, complete the starter quest chain, and earn gear as you level up.

## Development

1. Open Godot 4.7 Standard. The project uses GDScript and the Compatibility renderer.
2. In Godot Project Manager, choose **Import** and select `project.godot`.
3. Open the project. Once the main scene is in place, press **F5** to play.

The [implementation plan](docs/stonewatch-implementation-plan.md) covers the starter zone, controls, milestones, and playtest checklist. Use the local `builds/` directory for Windows exports.
